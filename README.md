# LongGrowthGene
sll of my rimworld mods so far have been made with claude. this is not different.  

This is a gene which makes the pawn start with most of it's capacities at 80%. But every in game day their capacities and resistances gain 1 percentage point.  

in total, it modifies most pawn metrics.  
list of metrics:
* consciousness
* sight
* hearing
* moving
* manipulation
* talking
* breathing
* blood filtration
* blood pumping
* pain threshold
* cold resistance
* heat resistance
* sharp resistance
* blunt resistance
* toxicity resistance
* psychic sensitivity
* mental break threshold
* carrying capacity
* immunity gain speed
* injury healing factor
* melee hit chance
* melee dodge chance
* shooting accuracy
* aiming time factor
* ranged cooldown modifier
* social impact
* conversion power
* food depletion speed
* fun depletion speed
* sleep depletion speed
